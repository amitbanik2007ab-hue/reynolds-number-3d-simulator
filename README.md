# Reynolds Number 3D Simulator – JU – Free For All

An interactive educational simulator designed for first-year Chemical Engineering students at Jadavpur University.

## Features
- Interactive 3D pipe visualization
- Reynolds number calculation
- Laminar, transitional and turbulent flow classification
- Water, Oil, Honey and Air presets
- Adjustable velocity and pipe diameter
- Voice commands
- JU Hostel Story Mode
- Live engineering data table

## Formula

Re = (Density × Velocity × Diameter) / Dynamic Viscosity

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
